How these numbers are calculated
TLS = (Swim mi × 4.0) + (Run mi × 1.0) + (Bike mi × 0.25)
🏊 Swim × 4.0 — highest effort per mile
🏃 Run × 1.0 — baseline discipline
🚴 Bike × 0.25 — lowest effort per mile
ACWR = this week's TLS ÷ 4-week average TLS
Measures how sharply load is ramping. Sweet spot: 0.8–1.3 · Caution: 1.3–1.5 · Danger: above 1.5. Staying in the sweet spot builds fitness while keeping injury risk low.
Training hours = total moving time across every tagged activity (all sports, including strength), summed per week. Uses moving time, not elapsed — stops and breaks don't count.
Fitness score = 4-week rolling average of weekly TLS. This is the same chronic-load (CTL-style) model used by platforms like TrainingPeaks — it rises with sustained consistent training and falls during breaks or taper. A slow steady climb is the goal; sudden jumps mean load spikes.
Run pace index = (60 ÷ average run pace in min/mi) × 10, per week. Purely a normalized speed number so faster weeks plot higher — e.g. 8:00/mi = 75, 7:30/mi = 80. Weeks with under 2 run miles carry the previous value forward.
